# Screenshots Directory

This directory contains screenshots of the DefStuf application for use in the main README.md.

## Required Screenshots

Please add the following screenshots with the exact filenames specified:

### 1. Authentication & Registration
- `login.png` - Login screen
- `register.png` - Registration screen

### 2. Main Interface
- `main-dashboard.png` - Main menu with all options visible

### 3. Note Management
- `manage-areas.png` - Area management screen showing list of areas
- `create-note.png` - Note creation form with all fields visible

### 4. Study Sessions
- `study-config.png` - Study session configuration screen showing area selection, counters (New/Pending/Total), and configuration options
- `study-session-question.png` - Active study session showing term/concept with progress panel (before showing answer)
- `study-session-answer.png` - Active study session showing revealed answer with description, images, and rating buttons

### 5. Optional
- `view-sources.png` - Sources management/view screen (optional)

## Image Guidelines

- **Format**: PNG recommended for best quality
- **Resolution**: Minimum 1280x720, preferably 1920x1080 or higher
- **File Size**: Try to keep under 500KB each (use compression if needed)
- **Naming**: Use lowercase with hyphens (e.g., `study-session-answer.png`)
